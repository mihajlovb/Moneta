# Moneta — табла за лични финансии

Проект по предметот **Дизајн на интеракција човек-компјутер** (ФИНКИ). Django апликација за следење сметки, трансакции, буџети и цели за штедење, со фокус на UI/UX: јасна хиерархија, повратна информација, пристапност, мобилен приказ, темна тема и превод на македонски.

- **Апликација во живо:** https://moneta.onrender.com
- **Документација (GitHub Pages):** https://mihajlovb.github.io/moneta/
- **Демо најава:** `demo` / `demo1234`

> Бесплатниот Render сервер заспива по 15 минути неактивност, па првото отворање може да трае до една минута. Демо-податоците се враќаат на почетна состојба при секое рестартирање.

## Локално стартување

Потребен е Python 3.12 или понов.

```bash
python -m venv .venv
.venv\Scripts\activate            # Linux/macOS: source .venv/bin/activate
pip install -r requirements.txt
python manage.py migrate
python manage.py seed_demo        # креира/ресетира demo / demo1234
python manage.py setup_admin      # (опционално) администраторска сметка за /admin/
python manage.py runserver
```

Отворете http://127.0.0.1:8000 и најавете се со **demo / demo1234**.

Тестови: `python manage.py test`

## Функционалности

| Страница | Што нуди |
| --- | --- |
| Dashboard | Нето-вредност, приходи, трошоци и стапка на штедење со споредба со претходниот месец; паричен тек за 6 месеци; трошоци по категорија; буџети, трансакции, сметки и цели |
| Transactions | Групирани по ден, пребарување, брзи филтри, резиме, страничење; додавање/уредување/бришење |
| Accounts | Сметки по тип (тековни, кеш, штедни, кредитни), салдо во оригинална валута, поврзана дебитна картичка; кредитниот долг е обврска |
| Budgets | Месечен лимит по категорија со статус (во ред / блиску до лимит / над буџет); забрана на дупли буџети |
| Goals | Цели за штедење со процент, преостанат износ и рок |
| Recurring | Претплати и редовни плаќања, проценет месечен трошок, календар |
| Reports | Паричен тек за 12 месеци, трошоци по категорија, кумулативно нето-трошење |
| Markets | Цени на акции, индекси и крипто (Yahoo Finance, преку серверот) |
| Settings | Профил, валута за приказ, тема, јазик, известувања, CSV-извоз, промена на лозинка |

## Структура

```
config/                 Django поставки и URL-адреси
finance/
  models.py             Account, Category, Transaction, Budget, Goal, UserPreference
  services.py           Пресметки за таблата (нето-вредност, тренд, по категорија, валути)
  views.py              Сите прикази
  forms.py              Форми со валидација
  filters.py            django-filter за трансакции
  signals.py            15 стандардни категории за секој нов корисник
  management/commands/  seed_demo, setup_admin
  templates/finance/    HTML шаблони
templates/              base.html, најава, admin
locale/mk/              Македонски превод
static/                 CSS, JS, лого, Lucide икони
docs/                   Страница за GitHub Pages
render.yaml, build.sh, start.sh   Објавување на Render
```

## Валути

Збировите преку повеќе сметки (табла, извештаи, буџети) прво се претвораат во MKD, а потоа во валутата што корисникот ја избрал за приказ. Буџетите и целите се во MKD; поединечните сметки и трансакции остануваат во својата валута. Курсевите во `finance/services.py` се **фиксни демо-вредности**, не во живо.

## Објавување

GitHub Pages служи само статички фајлови, па Django апликацијата е на Render, а Pages ја содржи документацијата (`docs/`).

**Render:** New → Blueprint → изберете го ова репо. `render.yaml` го поставува сервисот:

- `build.sh` — инсталира зависности и собира статички фајлови (WhiteNoise)
- `start.sh` — миграции, демо-податоци, (опционално) администратор, gunicorn
- Променливи: `DJANGO_SECRET_KEY` (генериран), `DJANGO_DEBUG=False`; опционално `DJANGO_SUPERUSER_USERNAME` и `DJANGO_SUPERUSER_PASSWORD`

**GitHub Pages:** Settings → Pages → Source: *Deploy from a branch* → `main` / `/docs`.

## Ограничувања

- Курсевите на валути се фиксни; Markets зависи од неофицијален Yahoo Finance API.
- Поставките за известувања се зачувуваат, но испраќање е-пошта/push не е конфигурирано.
- На бесплатниот Render план SQLite базата се ресетира при рестартирање.
